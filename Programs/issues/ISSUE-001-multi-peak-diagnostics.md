# ISSUE-001: マルチピーク診断が単一ピーク比較になっている

## 背景

最新結果 `bayesian_v10_results_20260323_154136` では、`7.0T` と `9.0T` の図に `Δf ≈ 230 GHz` 級の大きなズレが表示された。

## 原因

`plot_posterior_predictive_spectra()` と `plot_posterior_predictive_spectra_combined()` が、`compute_cavity_peak_info()` を使って「最も目立つ 1 本のピーク」だけを比較している。  
複数ピークがあるケースでは、観測側と予測側で別のピーク枝を拾ってしまう。

## ボトルネック

- 実際のモデル誤差と、表示される誤差が一致しない
- 結果の解釈が人手依存になる
- 低磁場と高磁場の比較が不安定になる

## 解決策

- 観測ピーク列と予測ピーク列を全体で最近傍対応する共通関数を作る
- 距離閾値 `PEAK_MATCH_MAX_DISTANCE` を超えた場合は誤対応とみなし、ペナルティ扱いにする
- プロットには単一ピーク誤差ではなく `peak_MAE` と `FWHM_MAE` を表示する
